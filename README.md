# ⚔️ Dinner Quest

A Legend of Zelda–themed dinner invitation. Built as a single self-contained `index.html`, mobile-friendly so it can be opened straight from a texted link.

**Live site:** https://brobertuy-beep.github.io/dinner-quest/

## The quest
1. Enter email (for the calendar invite)
2. The Question of Destiny — the **No** button dodges the cursor and can't be clicked
3. Scroll of Considerations — night (3–14 Aug 2026), time, pets (leave/bring), takeaway fallback, cuisine (Brisbane top 10), dietary needs
4. Reminder notes (smile, outrageous stories, interest)
5. **Finish** opens a prefilled Google Calendar invite containing all answers, with the host added as a guest

No backend — everything runs client-side.
